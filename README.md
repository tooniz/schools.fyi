# schools.fyi

A levels.fyi-style leveling comparison for Ontario schools. The home page lines up Toronto independent schools against the Ontario curriculum by **how far through the learning sequence each level sits**, not by the grade number printed on it — so an accelerated Grade 5 can appear against Ontario Grade 6.

## How the leveling works

Ontario is the reference axis: each Ontario grade occupies exactly one progress row, JK through Grade 12, plus a small region for work that sits past Grade 12. Every other program is described by `OffsetRule`s in `data/leveling/`, one per program, subject, and grade band:

- **`offsetYears`** shifts a level along the axis. Fractional values are allowed and used — `+0.5` means the level is placed half a grade ahead.
- **`spanYears`** stretches a level across more than one Ontario row. This is how curriculum compression is shown: TFS covers Ontario Grades 6–8 in two years, so those two levels are drawn 1.5 rows tall.
- **`coverage`** marks bands a program does not teach, which is how Ontario's missing core French before Grade 4 is represented rather than faked.
- **`confidence`** is one of `documented`, `approximate`, `community-reported`, or `insufficient-evidence`. A zero offset backed by an explicit school statement ("depth rather than breadth") is *documented*, not *insufficient evidence*; the two are kept distinct.
- **`acceleratedPathway`** records an opt-in faster route (reach-ahead credits, streamed senior courses) without averaging a minority track into the whole cohort's level.
- **`evidenceIds`** must resolve, and official/school sources are displayed separately from community discussion.

The validator enforces that every taught grade of every program has exactly one rule per subject, that bands do not double-cover a grade, and that a program's levels never run backwards along the axis. Overlap *is* allowed in the data, because convergence is real.

### Drawing the matrix

`layoutMatrix` turns those rules into boxes, and it makes two adjustments so the picture stays readable without moving any level off the position its offset claims:

- **Gaps are closed by stretching backwards.** When a level jumps ahead of the one below it, it is drawn down to meet its predecessor instead of leaving a hole — Bayview Glen's SK is drawn across Ontario SK *and* Grade 1. The level's claim, and the Ontario equivalent shown in its detail panel, stay at the real position; only the box grows.
- **Crowding widens the row for everyone.** Where a program puts two levels on the same stretch of the axis, that stretch is given proportionally more height and every other column crossing it grows to match, so converging levels stack instead of overlapping. Bayview Glen's Grade 8 and Grade 9 both sit at Ontario Grade 9 in mathematics, so that row is drawn double height in every column.

Both are pure layout: `progressStart` and `progressEnd` keep the unadjusted values, and the tests assert that no column ever has a gap or an overlap between consecutive levels.

Two smaller rules keep empty space from reading as missing data. Years outside a program's range are labelled rather than left blank — "UTS starts at Grade 7", "RHMS ends after Grade 8" — and the spare rows past Grade 12 are only drawn when some level actually reaches them, so an all-on-pace comparison does not trail off into a dead band. Column headers also distinguish a zero we can stand behind from one we cannot measure: *level with Ontario* means the placement is evidenced, *no documented offset* means it is not.

## Development and checks

Requires Node 20.9+. Run `npm install`, then `npm run dev`. Quality gates are `npm run validate:data`, `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`.

## Data workflow

Leveling data lives under `data/leveling/`: `programs.ts` (columns and their own level names), the `*-evidence.ts` files (every citable source, with the quote that supports the placement), and the `*-offsets.ts` files (the rules). Expectation-level detail for the older strand-by-strand comparison lives under `data/<provider>/<subject>.ts`.

Each program carries three names, because they are read in different amounts of space: `name` is the formal one used for search, `displayName` heads the column and the picker, and `abbreviation` labels the selected-track chip. Programs are tinted by `kind` — public curriculum, independent school, or international framework — so the type of thing being compared is visible before reading a word.

To add or change a placement: quote a primary source, record its URL and access date, write the `claim` and `rationale` so a reader can disagree with your reasoning, and pick the confidence tier honestly. Follow `CONTRIBUTING.md` and run all gates.

## Deployment

Pushes to `main` deploy a static export to the default GitHub Pages project URL. In the repository's **Settings → Pages**, select **GitHub Actions** as the source. The deployment workflow supplies GitHub's project base path, builds the site, and publishes `out/`; no environment variables or database are required.

To reproduce the Pages build locally, run `STATIC_EXPORT=true NEXT_PUBLIC_BASE_PATH=/schools.fyi npm run build` and serve `out/`. The contribution form intentionally links to a GitHub review queue and should be updated if the repository moves.

## Scope and limitations

The columns are the Ontario curriculum, six Toronto-area independent schools (Bayview Glen, Havergal College, Bishop Strachan, Toronto French School, University of Toronto Schools, Richmond Hill Montessori), and two international frameworks (Advanced Placement, International Baccalaureate), across mathematics, English/language, and French. Five can be compared at once; adding a sixth drops the leftmost.

What the current data does and does not support:

- **Bayview Glen** is the clearest whole-cohort acceleration. Its Director of Teaching and Learning states the mapping outright — "Our Senior Kindergarten students do the Grade 1 math curriculum, and our Grade 1s do the Grade 2 curriculum–and so on" — the Prep School page claims students work "one year ahead of their peers in other schools", and the Grade 6 booklet prints its mathematics section under a "Grade 7 Curriculum" heading. Mathematics is `+1.0` and `documented` from SK to Grade 8.
- **TFS** is the most structurally different: the school states that "our students have earned most Ontario Grade 9, 10 and 11 credits a year ahead of their peers in the province", and it compresses Ontario Grades 6–8 into two years. It is also the only program that sits *behind* Ontario anywhere — there is no English instruction at all before Grade 2, because "from Jardin d'éveil Hafez (age 2) to Grade 1, our program is entirely in French".
- **Havergal** is placed level with Ontario in mathematics and English *by its own stated design* — it teaches "for depth rather than for breadth" and is openly sceptical of condensed programs. French is the exception and is `+1.0` for every student from Grade 3 through Grade 9: the course calendar has Grade 7 taking Grade 8 French and Grade 8 taking FSF1D, the Ontario Grade 9 course, "for all students".
- **BSS** keeps the Ontario sequence, and its Junior School page is specific enough to check: the number range taught in each grade (to 50 in Grade 1, to 10,000 in Grade 4, to 1,000,000 in Grade 6) matches Ontario exactly, grade for grade. Its one documented acceleration is an opt-in Grade 7–8 math and French stream, which 25% of Grade 8 students use to earn a Grade 9 credit. That minority track is recorded as a pathway rather than blended into the cohort's level.
- **UTS is the one placement that can be checked course code by course code.** Its own course chart shows Ontario codes taken a year early throughout: MPM1D in Grade 8, MPM2D in Grade 9, MCR3U in Grade 10, MHF4U in Grade 11. The Grade 7 year is a UTS-internal course with no Ontario code, so it is drawn two rows tall — absorbing Ontario Grades 7 and 8 is the only way the following year reaches Grade 9 math. The lead is *not* spent finishing early: Grade 12 returns to Ontario Grade 12 courses, so the last two years converge on the same row and the year gained buys AP breadth instead. English is the instructive contrast — the same chart shows ENG1D through ENG4U dead on the Ontario grade, and UTS advertises acceleration for mathematics and science on the same page while never once claiming it for English. Two cautions: the course chart is the 2015–16 calendar, corroborated only qualitatively by the current site, and UTS accelerates the whole cohort while explicitly refusing individual acceleration — "Individual fast tracking and early course specialization are not compatible with our philosophy."
- **RHMS is the counterexample, and it is here on purpose.** It is a private school that sits level with Ontario on its own evidence rather than for want of evidence. Arguing *against* multi-age classes, RHMS uses mathematics as its example — "in a single Grade three class, the teacher would teach Grade three math concepts" — and concludes that single grades ensure "the appropriate curriculum, at the appropriate time." Its mathematics page claims rigour and never claims a grade advantage. French begins in Grade 4, exactly when Ontario's does, which makes it the only column that starts French on the same row as the province. Two structural facts worth knowing: the Montessori programme covers only the Kindergarten years, so Grades 1–8 are conventional single-grade classes and no Lower/Upper Elementary triads exist here; and there is no secondary school, so Grades 9–12 are empty. Its CAT4 averages are not used — an achievement score cannot be converted into a curriculum offset.
- **AP and IB are overlays, not schools, and are scoped accordingly.** Both columns start at Grade 9 and leave the elementary rows empty rather than inventing coverage — for AP that is a rule, not a choice, since the Course Audit only authorizes courses "offered exclusively in grades 9–12". Their placements refuse to take "college-level" at face value and are weighed against Ontario transfer-credit policy instead, which produced the most uncomfortable finding in the dataset: **Ontario universities do not agree with each other.** Queen's grants AP Calculus BC a full first-year credit (MATH 121, 6.0 units) and Guelph grants MATH 1080, while U of T Arts & Science grants nothing for any AP calculus. Queen's grants nothing for AP English; Guelph grants a full credit; U of T grants half. Offsets follow the weight of that evidence and are held at `approximate`, because a placement that reverses depending on the registrar is not documented. An earlier version of this site derived AP placements from one university's table alone and had AP English a year ahead of AP mathematics; the wider evidence reverses that, and it is the clearest example of why single-source placements are dangerous here.
- **IB is placed as Ontario actually delivers it.** The Primary and Middle Years Programmes are omitted: no TDSB school runs them. What is shown is the real route — two Pre-IB years that "move through the Ontario Curriculum at an accelerated pace", with the TDSB's own examples being that "Math 9 covers some content from the Ontario Grade 10 math curriculum" and that students complete "Grade 11 Ontario courses in the Grade 10 year", followed by the two-year Diploma. The final Diploma year is drawn tall because a student takes three Higher Level subjects, which earn a full first-year credit, alongside three Standard Level subjects, which earn none at any university checked. The cleanest available comparison between the two frameworks is Queen's, where one registrar in one year maps both AP Calculus BC and IB HL Mathematics to MATH 121, both AP French and IB HL French to FREN 150, and grants **neither** AP English nor IB HL English any credit at all. AP and IB are therefore placed level with each other in all three subjects rather than one leading, and English is held back for both.
- **Same-position convergence is shown, not smoothed away.** Bayview Glen's Grade 8 and Grade 9 both sit at Ontario Grade 9 in mathematics, because the elementary lead is banked as credits and the Upper School re-anchors to Ontario course codes. The validator rejects only true inversions.
- **"On Ontario pace" is suppressed where Ontario teaches nothing.** A level sitting at zero offset against an empty provincial column is labelled *no Ontario counterpart* instead, so TFS's French-medium Kindergarten is not misread as merely keeping up.
- **French offsets are floors, not measurements.** Ontario's core French ladder (600 hours by Grade 8) cannot express how far ahead a French-medium school is; TFS teaches French "at a mother tongue level" and is capped at `+3` for that reason, and says so in its rationale.
- Kindergarten placements are marked `insufficient-evidence` because no school publishes a Kindergarten comparison against Ontario's.
- **Community and forum evidence on these schools' grade mappings is close to non-existent**, and the data reflects that rather than padding it. Searches across Reddit, RedFlagDeals, College Confidential, and parenting forums produced no thread in which anyone claims a specific grade offset for any of these four schools. Two attribution traps are worth knowing about: a widely-surfaced PDF labelled "Academic Program" is **Greenwood College School's** handbook, not BSS's, and a "curriculum that runs ahead of the Ontario standard" line belongs to a tutoring company advertising itself. Neither is cited here. Directory sources (Our Kids, Wikipedia) are labelled `secondary-directory` rather than dressed up as primary.

Alignments are editorial aids, not accreditation, placement advice, or formal equivalencies.
